# Nginx TLS Test Project
## Что сделано:
1. Создан новый раздел руководства администратора по настройке защищенного HTTPS-соединения на веб-сервере Nginx.
2. Описан пошаговый процесс развертывания веб-сервера, генерации самоподписанного TLS/SSL сертификата с помощью OpenSSL и настройки обратного проксирования (Reverse Proxy) на локальный порт бэкенда 8080.
3. Добавлен архитектурный блок в формате Mermaid-диаграммы, визуализирующий путь трафика от клиента через Nginx к бэкенду.
4. Сформирована таблица основных директив конфигурационного файла Nginx и добавлен раздел Troubleshooting с 3 типовыми неисправностями (502 Bad Gateway, блокировки SELinux, предупреждения самоподписанных сертификатов) и методами их решения.

## Как протестировать изменения:
Проверить корректность рендеринга Markdown-страницы и Mermaid-диаграммы в интерфейсе системы управления документацией (или GitHub/GitLab).
